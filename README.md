# 鐵匠模擬遊戲

> 建立日期：2026-10-29
> 最後更新：2026-11-06
> 類型：概覽
> 適用對象：Glen 自己；換機器繼續開發時從這份進

---

奇幻中古世紀背景的鐵匠模擬遊戲。主角是一名女鐵匠，每天接訂單，用真實的鍛造工序把東西做出來，依照客人需求與成品屬性被評分。

核心主張：玩法重現的是鐵匠真正在做的判斷，看爐火顏色決定溫度、揮錘決定金屬往哪流、盯回火色決定什麼時候收手。

目前階段：設計文件完成，2D 揮錘原型可以跑，3D 版的第 0 刀（揮錘測試台）與第 1 刀（加熱與火次循環）都會動了。

2026-11-06 翻掉一條前提：鏡頭從固定側視改成第一人稱 3D。取捨與技術選型寫在
`07_3D 化設計與技術選型.md`（在這個 repo 的上一層，Glen 的 vault 裡）。

## 快速入口

- **3D 版（第 0 刀）**：`npm install && npm run dev`，開 http://localhost:5180
- **模型自檢**：`npm run check:model`，驗體積守恆、延展方向、網格繞序
- **熱模型自檢**：`npm run check:heat`，驗局部加熱、一火的錘數、薄處先冷、爐火與過熱
- **2D 原型（揮錘測試台）**：`prototype/hammer-testbed.html`，用瀏覽器直接開，不需要任何建置
- **線上版（3D 第 0 刀）**：https://wenglen.github.io/theBlacksmith/ ，推到 main 會自動建置部署。滑鼠拖曳加鍵盤操作，手機開不起來玩
- **線上版（2D 原型）**：https://claude.ai/artifact/Wk1qCEUwb9daxcoLFRhUUt （私人連結，只有 Glen 開得起來）
- **從哪份看起**：[00_總覽.md](00_總覽.md)

## 3D 版（第 0 刀）做到哪

React 19 + TypeScript + three.js（React Three Fiber），Vite 建置。

已實作：

- 第一人稱鍛打工位：鐵砧（砧面、砧角、收腰砧身、硬斬孔、木墩）、爐火、暗房
- **落點是 raycast 打在工件網格上的世界座標加表面法線**，不是螢幕座標。鏡頭動了它還黏在那塊鐵上
- 揮錘狀態機原封不動沿用 2D 原型那一套（`src/game/input/swing.ts`），一行都沒改
- 工件是脊線＋斷面堆疊（48 段 × 16 個角度取樣），一錘壓下去的斷面積會往兩側展寬與變成長度，體積守恆
- 連續翻轉與連續送料：Q／E、A／D 點一下離散跳、按住不放連續
- 傾角投影到打擊點的切平面，工件轉過角度之後同一個手勢推金屬的方向就跟著變
- 動作進行中鏡頭完全鎖死，只有空手時右鍵拖才能環視
- 三種落點模式即時切換、落點散布圖、斷面示意、收手與冷作裂紋計數

還沒做：延展以外的工序、熱處理、研磨、訂單與評分、任何美術資產（全部是 primitive）。

程式分層（`07` 第六節的鐵律：每幀會變的東西不進 React state）：

| 目錄 | 內容 |
|---|---|
| `src/game/` | 純邏輯。不 import React，也不 import three.js，可以單獨跑測試 |
| `src/scene/` | R3F 元件與那層接線 |
| `src/ui/` | HUD。這一刀的 HUD 是驗收工具，正式版要照原則 3 把數字全部拿掉 |
| `src/state/` | session（普通可變物件）與 HUD store（節流推上去） |
| `scripts/` | `check:model`：三條壞了也看不出來的性質檢查 |

## 2D 原型做到哪

`prototype/hammer-testbed.html` 是單一檔案，沒有相依套件。

已實作：

- 揮錘的完整狀態機：按住鎖定落點、左右甩動（後擺蓄力、前擺出力）、放開落錘、甩回原點收手、按住不放進連打
- 三種落點模式可即時切換，各自累積散布統計，下方有比較表
- 第一人稱視角：固定鐵砧（砧面、砧角、收腰砧身、硬斬孔），鐵柱沿右上左下躺在上面
- QEAD 四個斜方向推料，E／A 沿料身送、Q／D 橫越砧面；推到砧角或砧面外再打，料只會被壓彎
- WS 翻面。四個面各自存自己的錘痕與裂紋，一次看得到朝上與朝你兩面
- 熱度、冷作裂紋、燒損、節奏加成、斷面方扁判定

還沒做：延展以外的工序、熱處理、研磨、訂單與評分。

## 換機器怎麼接手

```
git clone https://github.com/WenGlen/theBlacksmith.git
cd theBlacksmith && npm install && npm run dev
```

文件平常放在 `D:\Obsidian\其他\鐵匠`，要用 Obsidian 讀就把 clone 下來的內容放回那個路徑（或在新機器的 vault 裡對應的位置）。原型直接用瀏覽器開 `prototype/hammer-testbed.html` 就能跑。

下一步照 [05_開放問題與下一步.md](05_開放問題與下一步.md) 的「建議的製作順序」，以及 [06_輸入狀態機與動作文法.md](06_輸入狀態機與動作文法.md) 第三節那三個要實測的分歧。
